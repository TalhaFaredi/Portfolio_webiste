AI I Work With Now

Frontier models and the ideas behind them, as of October 2026. Short on purpose.

Muse Wonder & Wonder Full

Meta, 12 Oct 2026. Personal and professional agents with Active Memory and Active Focus. 1M-token context; text, image, video, and audio in. Wonder is on the Meta API and Muse Code; Full is for Muse Code subscribers. Artificial Analysis Intelligence Index: Full 56, Wonder 52, Muse Spark 1.3 at 48.

Jev 1.13

TypeSafe System One model. It does not write text. You pass state plus a typed question; it returns a choice, a score, or a yes/no probability. Trained with RLCD so the confidence is meant to be calibrated. I use this pattern for routing, filtering, and guardrails inside agent loops.

Opus, GPT, and Argon

Claude Opus and Sonnet 5.5 for coding agents, GPT including GPT-6.1 Sol for multi-step work, and Gemini 4 Argon for long trajectories. Muse Spark, Qwen, and DeepSeek when the model needs to run or be fine-tuned locally.

Agent harness & prime agents

A prime agent plans, writes todos, and delegates to subagents inside an agent harness: filesystem memory, tool use, and a human checkpoint. LangGraph and MCP wire that harness to the apps around it.

LLMs, SLMs & fine-tuning

LLMs for open-ended work; small language models (SLMs) where latency and cost matter. Adaptation with LoRA and QLoRA, PEFT, and efficient fine-tuning plus GPTQ/AWQ quantization so one base model fits many products.

Logical agentic systems

Agents wired as explicit graphs: conditions, tool calls, and typed outputs your code can branch on — not one long chat loop. Same idea for local SLMs on a GPU box or frontier models on Bedrock.

Generate vs decide

Wonder-class models draft, code, and plan. Jev-class models pick among options you already defined. Most of my systems call both: a generator for open work, a decision model where the answer must be a type the code can branch on.

Wireless Systems — Current Work

M.S. research with the Intelligent Wireless Systems Lab at Chung-Ang. AI on the physical layer of 5G/6G.

ISAC

Integrated sensing and communication: one waveform carries data and estimates range, velocity, and biosignals from the echo. Current lab work covers transmit/receive beamforming and sensing for UAV, UAM, and vehicles.

Intelligent reflecting surfaces

Passive metasurfaces that steer a link. Latest threads are hybrid RIS phase design from channel or direction-of-arrival estimates, and phase mapping that still works once signaling overhead is counted.

Space-time line coding

STLC gives full spatial diversity with a simple receiver. I follow IRS-aided STLC: the surface and the line code designed together so a low-complexity radio still gets the rate.

Learning at the PHY

CNNs for RIS phase control, Kalman tracking for urban air mobility and LEO, and WiFi sensing. The point is a receiver or scheduler that adapts without a heavy optimization loop on every slot.
